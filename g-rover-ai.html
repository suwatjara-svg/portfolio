G-Rover AI

Robot อัจฉริยะที่ออกแบบโดยใช้ Board ESP32 CAM ควบคุมง่ายผ่านโทรศัพท์มือถือ

รายละเอียดโปรเจกต์

G-Rover AI เป็นหุ่นยนต์ที่ออกแบบโดยใช้บอร์ด ESP32 CAM และสั่งงานควบคุมด้วยโทรศัพท์มือถือผ่านโหมด AP MODE (Access Point)

  • Connectivity: ESP32 CAM ทำหน้าที่เป็น SERVER และมือถือเป็น CLIENT เชื่อมต่อกันได้โดยตรงไม่ต้องผ่าน Router
  • Function: มาพร้อมฟังก์ชั่นตรวจจับวัตถุ (Object Detection) เพิ่มความฉลาดให้กับหุ่นยนต์
  • Alternative Mode: มีโค้ดรองรับการทำงานแบบ STA MODE สำหรับเชื่อมต่อผ่าน WiFi Network
