# 💎 Gemini Assistant — Word Add-in (Conversational Edition)

> AI-Powered Writing Assistant สำหรับ Microsoft Word ในรูปแบบแชทโต้ตอบโต้ตอบต่อเนื่อง (Multi-turn Chat)  
> ทำงานร่วมกับ Google Gemini API เพื่อช่วยตรวจสอบ เกลา แก้ไข และตรวจสอบความสอดคล้องระหว่างเอกสารหลักกับไฟล์แนบอ้างอิง

---

## 📁 โครงสร้างไฟล์ (Project Structure)

```
Office-Web-Add-in/
│
├── manifest.xml          ← ไฟล์ลงทะเบียน Add-in (บอก Word ว่า Add-in ชื่ออะไร โหลดจากไหน)
├── package.json          ← สคริปต์เปิดรันระบบและรายชื่อ Dependencies
├── taskpane.html         ← โครงสร้างหน้าแชท UI ธีมมืดระดับพรีเมียม
├── taskpane.css          ← สไตล์ Dark Theme, ฟองคำพูด (Chat Bubbles) และปุ่มคำสั่ง
├── taskpane.js           ← ตรรกะควบคุมทั้งหมด (ระบบแชท, ดึงข้อมูล Word, อ่านไฟล์ภายนอก, เชื่อม API)
├── highlightReview.js    ← โมดูลจัดการทำ Highlight สีเหลือง และแทรกคอมเมนต์ (Comments) ลงกระดาษ Word
│
├── assets/               ← โลโก้แอปพลิเคชัน (32px และ 64px)
├── manifests/            ← สำเนาสำหรับอ้างอิง Trusted Catalog
└── CODE_ANALYSIS.md      ← วิเคราะห์ระบบโค้ดอย่างละเอียด
```

## ⚙️ ฟังก์ชันและหลักการทำงานของโค้ด (Core Logic)

สถาปัตยกรรมของ Add-in ได้รับการออกแบบให้ทำงานแบบ **Local Client-Side** ข้อความและไฟล์ทั้งหมดจะถูกประมวลผลภายในเบราว์เซอร์จำลองของ Word และเรียกหา Google Gemini API โดยตรงผ่าน HTTPS เพื่อความปลอดภัยสูงสุด

```
[ผู้ใช้เลือกแนบไฟล์ + กดปุ่มตรวจสอบ]
       ▼
[อ่านข้อมูลสะสมในเอกสาร Word + ไฟล์อ้างอิง]
       ▼
[ส่งข้อมูลวิเคราะห์เข้า Gemini API ในโหมด JSON]
       ▼
[ประมวลผลเสร็จ ทำการ Highlight สีเหลือง + ปัก Comment ใน Word อัตโนมัติ]
       ▼
[แสดงกล่องการ์ดคำผิดเฉพาะจุดบนหน้าจอแชท]
       ▼
[ผู้ใช้คลิกเลือก: "แก้ไข" เพื่อเปลี่ยนคำทับเฉพาะจุด หรือ "คัดลอก"]
```

### รายละเอียดในแต่ละส่วนประกอบ:

#### 1. ระบบจำประวัติสนทนา (Multi-turn Chat)
*   **หลักการ:** ใน `taskpane.js` จะมีตัวแปรอาร์เรย์ `chatHistory` คอยสะสมการโต้ตอบในรูปแบบ `[{ role: "user"|"model", parts: [{ text: string }] }]`
*   **ความสามารถ:** ทำให้ผู้ใช้งานพิมพ์สั่งงานต่อยอดต่อเนื่องได้ทันที เช่น หลังจากตรวจสอบเทียบไฟล์แนบเสร็จสิ้นแล้ว สามารถแชทสั่งงานแก้ไขส่วนอื่นต่อเนื่องได้
*   **ปุ่มล้างแชท (New Chat):** กดที่มุมขวาบนเพื่อทำการเคลียร์ข้อมูลใน `chatHistory = []` และล้างประวัติแชทบนหน้าจอเพื่อเริ่มหัวข้อใหม่

#### 2. ปุ่มพิเศษ "🔍 ตรวจสอบเทียบไฟล์แนบ" (Verify Consistency with Attachments)
*   **หลักการ:** เปรียบเทียบระหว่างเอกสารหลักใน Word และเอกสารแนบประกอบภายนอกผ่านโหมด JSON (บังคับรูปแบบ `responseMimeType: "application/json"`)
*   **การทำงานอัตโนมัติ:** เมื่อวิเคราะห์ความขัดแย้ง 5 หัวข้อ (เนื้อหา, ชื่อแผนงาน/โครงการ, ยอดเงินเรื่องย่อย, การแยกเรื่อง, รูปแบบราชการ) เสร็จแล้ว **ระบบจะทำการทำ Highlight สีเหลือง พร้อมเขียนความเห็นแนะนำ (Comments) ลงกระดาษ Word อัตโนมัติทันที** ทุกจุดที่แจ้งว่าพบข้อผิดพลาด
*   **ปุ่มการควบคุมเฉพาะคำ:** ใต้ข้อสรุปแต่ละรายการจะไม่มีปุ่มแทรกหรือเขียนทับทั้งหน้ากระดาษ แต่จะแสดงเป็นปุ่ม **`✔ แก้ไข`** (แก้ไขข้อความที่แนะนำเฉพาะคำเดี่ยวนั้นลง Word) และปุ่ม **`📋 คัดลอก`**

#### 3. ระบบอ่านไฟล์อ้างอิงในเครื่อง (Local Parsing)
ระบบทำงานแบบออฟไลน์บนเครื่องของผู้ใช้ในการดึงข้อความตัวอักษร โดยมีฟังก์ชันแกะไฟล์แยกตามประเภท:
*   **Word (.docx):** ใช้ไลบรารี `mammoth.js` เพื่อดึงเนื้อหาข้อความดิบ
*   **Excel (.xlsx):** ใช้ไลบรารี `xlsx.js` (SheetJS) เพื่อแปลงตารางแผ่นงานให้อยู่ในรูปข้อความตาราง CSV
*   **PDF (.pdf):** ใช้ไลบรารี `pdf.js` เพื่อดึงตัวอักษรจากเนื้อหาในแต่ละหน้า

#### 4. ระบบบันทึก API Key อัตโนมัติ (API Key Memory)
*   **หลักการ:** บันทึกผ่าน `localStorage` ทันทีเมื่อผู้ใช้ป้อนคีย์ และโหลดกลับมาแสดงผลให้อัตโนมัติเมื่อเปิด Add-in ครั้งต่อไป
*   **ความสะอาดตา:** แผงตั้งค่าและช่องป้อนรหัสจะซ่อนอยู่ใต้เมนู **`☰`** ด้านซ้ายบนสุด ทำให้หน้าจอด้านขวาดูสะอาดตาคล้ายกับแอปพลิเคชัน Copilot จริง

## 🚀 ความสามารถและการใช้งานหลัก (Use Cases)

Gemini Assistant สามารถช่วยเหลือคุณจัดการเอกสารในเรื่องต่างๆ ดังนี้:

### 1. 🔍 การตรวจสอบเปรียบเทียบเอกสารและทำ Highlight อัตโนมัติ
*   **การใช้งาน:** แนบไฟล์อ้างอิง เช่น ตาราง Excel หรือร่างระเบียบเปิดฝึก แล้วกดปุ่มสีฟ้า **`🔍 ตรวจสอบเทียบไฟล์แนบ`**
*   **พฤติกรรม:** ระบบจะวิเคราะห์ข้อมูล และทำการระบายสีเหลือง (Highlight) จุดที่ตัวเลขไม่ตรงหรือสะกดผิดพร้อมเขียนคอมเมนต์ใน Word ให้ทันทีโดยที่ผู้ใช้ไม่ต้องกดเอง
*   **การตรวจสอบปุ่มแก้ไข:** ผลลัพธ์ในกล่องแชทจะแสดงข้อผิดพลาดแยกเป็นการ์ด กดปุ่ม **`✔ แก้ไข`** ใต้การ์ดนั้นๆ เพื่อเขียนเปลี่ยนคำถูกทับคำผิดใน Word ทันที (จะไม่มีปุ่มเขียนทับและแทรกที่ครอบคลุมเนื้อหาทั้งหน้าอีกต่อไป เพื่อความปลอดภัยของเอกสาร)

### 2. 📝 เขียนและโต้ตอบงานทั่วไปในช่องแชท (Conversational Chat)
*   พิมพ์สอบถามหรือสั่งเขียนบทความ ร่างจดหมาย ในช่องแชทด้านล่างตามปกติ คำตอบที่เป็นตัวอักษรจะแสดงผลเป็นฟองคำพูด AI แถบซ้ายพร้อมมีปุ่ม **`📋 คัดลอก`** เพื่อความสะดวกในการนำไปแปะใช้งานด้วยตนเอง

## 🛠️ ขั้นตอนเริ่มต้นใช้งาน (สำหรับนักพัฒนาและผู้ใช้ทั่วไป)

### ☁️ ตัวเลือกที่ 1: การใช้งานจริงผ่านคลาวด์ Vercel (ไม่ต้องเปิดเครื่องคอมเป็น Server)
ปัจจุบันโครงการได้รับการ Deploy ขึ้นสู่ Vercel เรียบร้อยแล้วที่ลิงก์:
👉 **[https://office-web-add-in.vercel.app](https://office-web-add-in.vercel.app)**
หากใช้ตัวเลือกนี้:
1. นำไฟล์ `manifest.xml` (ตัวที่อัปเดตชี้ลิงก์ Vercel แล้ว) ไปวางไว้ในโฟลเดอร์แชร์ของเครื่อง (`C:\AddinManifests\manifest.xml`)
2. เปิดโปรแกรม Word แล้วเรียกใช้งานได้ทันทีโดยไม่ต้องรันคำสั่งใดๆ ในเครื่องค้างไว้!

### 💻 ตัวเลือกที่ 2: รันทดสอบในเครื่องตัวเอง (Local Development)
เมื่อต้องการแก้ไขโค้ดและเปิดจำลอง Server ในเครื่องตัวเองเพื่อพัฒนาต่อ:

#### ขั้นตอนที่ 1: เปิด Server
เปิด PowerShell ของ Windows ขึ้นมา จากนั้นรันคำสั่ง:
```powershell
cd D:\onedrive\Code\Office-Web-Add-in
npm run dev
```
*(ให้เปิดค้างหน้านี้ไว้ตลอดเวลาที่เรียกใช้งาน ห้ามปิดหน้าต่างนี้)*

#### ขั้นตอนที่ 2: เรียกใช้ Add-in ใน Word
1. เปิดโปรแกรม Microsoft Word ขึ้นมา
2. ไปที่แถบเมนู **แทรก (Insert)** หรือ **หน้าแรก (Home)** → คลิกปุ่ม **Add-ins**
3. เลือกเมนู **Add-in ของฉัน (My Add-ins)**
4. เลือกแท็บ **โฟลเดอร์ที่แชร์ (Shared Folder)** → เลือก **Gemini Assistant** เพื่อเปิดหน้าจอแถบขวาขึ้นมา

#### ขั้นตอนที่ 3: เปิดใช้งานและแชทโต้ตอบ
1. หากเริ่มใช้งานครั้งแรก กดปุ่ม **`☰`** มุทซ้ายบนสุด เพื่อวาง API Key ของคุณ
2. แนะนำโมเดลเริ่มต้นความเร็วสูงและปลอดภัย **`gemini-3.1-flash-lite`**
3. พิมพ์คำสั่งลงในช่องข้อความด้านล่างสุด แล้วกด **`Enter`** (หรือคลิกปุ่มส่ง `➔`) เพื่อโต้ตอบกับ AI ได้ทันที!
4. หากต้องการส่งคำสั่งขยายหลายย่อหน้า ให้กดปุ่ม **`Shift + Enter`** เพื่อขึ้นบรรทัดใหม่
