LINE BOT จัดเก็บไฟล์อัตโนมัติ

รับไฟล์จาก LINE OA อัตโนมัติ จัดเก็บลง Google Drive และตรวจสอบย้อนหลังผ่าน Dashboard ได้ทันที

ภาพรวมระบบ

ระบบพัฒนาด้วย Google Apps Script โดยทำงานเป็นลำดับ: LINE OA ส่งไฟล์เข้า Webhook, ระบบบันทึกไฟล์ลง Google Drive, เก็บข้อมูลลง Google Sheets (Logs/DeleteLogs), และแสดงผลผ่านหน้า Dashboard สำหรับค้นหา ลบ และกู้คืนไฟล์

Video Guide

วิดีโอสอนการติดตั้งระบบ

สำหรับผู้ที่ต้องการดูขั้นตอนจริงแบบเห็นหน้าจอ วิดีโอนี้จะพาไล่ตั้งค่าระบบตั้งแต่เตรียมไฟล์ ไปจนถึงการเชื่อมต่อ Webhook และทดสอบใช้งาน

เปิดวิดีโอติดตั้งบน YouTube

1) เตรียมสิ่งที่ต้องใช้ก่อนเริ่ม

  • บัญชี Google ที่ใช้งาน Google Drive / Google Sheets ได้
  • บัญชี LINE Developers และ LINE Messaging API Channel
  • ไฟล์โค้ด 2 ไฟล์หลัก: Code.gs และ Index.html
  • สิทธิ์ในการ Deploy Apps Script เป็น Web App

2) เตรียม Google Drive และ Google Sheets

  • สร้างโฟลเดอร์ใน Drive จำนวน 2 โฟลเดอร์: รูปภาพ และ เอกสาร
  • คัดลอก Folder ID ของแต่ละโฟลเดอร์จาก URL (ส่วนหลัง /folders/)
  • สร้าง Google Sheets ใหม่ 1 ไฟล์ สำหรับเก็บข้อมูล Log
  • คัดลอก Spreadsheet ID จาก URL ของไฟล์ Google Sheets

3) วางโค้ดใน Apps Script

  • เปิด Google Sheets แล้วไปที่เมนู Extensions > Apps Script
  • ลบโค้ดเดิมในไฟล์ Code.gs แล้ววางโค้ดใหม่ทั้งหมด
  • สร้างไฟล์ HTML ใหม่ชื่อ Index แล้ววางโค้ดจาก Index.html
  • กดบันทึกไฟล์ทุกครั้งก่อนเริ่มขั้นตอนถัดไป

4) ตั้งค่า CONFIG ใน Code.gs

  • ตั้งค่า CHANNEL_ACCESS_TOKEN จาก LINE Developers
  • ตั้งค่า SPREADSHEET_ID, IMAGE_FOLDER_ID, DOC_FOLDER_ID
  • กำหนด DASHBOARD_ADMIN_EMAILS เป็นอีเมลผู้ดูแลจริง
  • กำหนด MAX_FILE_SIZE_MB ตามนโยบายองค์กร
  • แนะนำ: ใช้ PUBLIC_FILE_LINK_ENABLED = false ถ้าไฟล์เป็นข้อมูลภายใน

5) Deploy เป็น Web App

  • กด Deploy > New Deployment แล้วเลือกชนิด Web app
  • ตั้งค่า Execute as และ Who has access ให้ตรงนโยบายหน่วยงาน
  • กด Deploy และอนุญาตสิทธิ์ที่ระบบร้องขอให้ครบ
  • คัดลอก Web App URL เก็บไว้สำหรับใช้เป็น Webhook URL

6) ผูก Webhook กับ LINE Developers

  • เปิด LINE Developers > Messaging API
  • นำ Web App URL ไปใส่ในช่อง Webhook URL
  • กด Verify ให้ผ่าน แล้วเปิด Use webhook เป็น Enabled
  • หาก Verify ไม่ผ่าน ให้ตรวจ URL ล่าสุดจาก deployment ปัจจุบัน

7) Initialize โครงสร้างชีต

  • ใน Apps Script ให้เลือกฟังก์ชัน editSheet() แล้วกด Run
  • ระบบจะสร้าง/ซ่อมชีต Logs, DeleteLogs, Settings
  • ตรวจว่ามี Header ครบทั้ง 3 ชีตก่อนเริ่มทดสอบใช้งานจริง

8) ทดสอบระบบก่อนใช้งานจริง (Checklist)

  • ทดสอบส่งรูปผ่าน LINE: ไฟล์ต้องเข้าโฟลเดอร์รูป และมี Log เพิ่ม
  • ทดสอบส่งเอกสารผ่าน LINE: ไฟล์ต้องเข้าโฟลเดอร์เอกสาร และมี Log เพิ่ม
  • ทดสอบคำสั่งตั้งชื่อ เช่น ชื่อ: อบรมความปลอดภัย รุ่น 3 แล้วส่งไฟล์ 1 รายการ
  • ทดสอบ Dashboard: ค้นหา, กรองประเภทไฟล์, และแบ่งหน้า
  • ทดสอบสิทธิ์ admin: ลบไฟล์, ตรวจ DeleteLogs, และกู้คืนไฟล์

ข้อควรทำก่อนเปิดใช้งานจริง

  • เปลี่ยนรหัสผ่าน Dashboard เริ่มต้นในชีต Settings ทันที
  • ทบทวนรายชื่อ admin และสิทธิ์การเข้าถึงเป็นรายเดือน
  • สำรองข้อมูลชีตและตรวจสอบ token/URL สำคัญให้อยู่ในที่ปลอดภัย
