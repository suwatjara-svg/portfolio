Gemini Assistant — Word Add-in

AI-Powered Writing Assistant แบบ Sidebar สำหรับ Microsoft Word
ช่วยตรวจสอบ เกลาสำนวน แก้คำผิดราชการ และเปรียบเทียบเอกสารแนบด้วยระบบ AI อัจฉริยะ

ความสามารถของโปรแกรม

Gemini Assistant เป็นโปรแกรมเสริมสำหรับ Microsoft Word (Office Web Add-in) ที่ถูกออกแบบมาเพื่อยกระดับการทำงานเอกสาร โดยเฉพาะการตรวจสอบความถูกต้องของเอกสารราชการ การเกลาภาษา และการเปรียบเทียบข้อมูลระหว่างเอกสารหลักกับไฟล์แนบอ้างอิงภายนอก

ตัวโปรแกรมรันในระบบ Client-Side 100% เชื่อมต่อโดยตรงหา Google Gemini API ผ่านเว็บเบราว์เซอร์ของ Word ไม่ต้องพึ่งพาเซิร์ฟเวอร์คนกลาง ช่วยรักษาความลับของเอกสารและ API Key ของคุณอย่างปลอดภัยสูงสุด

ดาวน์โหลดโปรเจกต์ (Download Add-in)

ดาวน์โหลดซอร์สโค้ดและไฟล์ Manifest เพื่อนำไปติดตั้งใน Microsoft Word ของคุณ

ดาวน์โหลด Gemini Assistant

ประโยชน์และฟีเจอร์เด่น

🔍 ตรวจสอบความถูกต้องและทำไฮไลท์อัตโนมัติ

เมื่อแนบเอกสารอ้างอิงประกอบ (เช่น ตาราง Excel หรือเอกสารโครงการเดิม) และกดปุ่มเปรียบเทียบ ระบบจะตรวจสอบความขัดแย้ง 5 มิติ (เช่น ตัวเลขสะกดผิด รูปแบบทางการ ยอดเงินเรื่องย่อย) และระบายสีเหลือง (Highlight) พร้อมปักกล่องคอมเมนต์ (Comment) ข้อผิดพลาดลงหน้ากระดาษ Word ให้ทันทีโดยอัตโนมัติ

🗂️ การอ่านไฟล์ออฟไลน์ (Local Text Parsing)

รองรับการถอดข้อความจากไฟล์ในเครื่องของคุณแบบไม่ต้องส่งขึ้นเซิร์ฟเวอร์ โดยรองรับทั้งเอกสาร Word (.docx) โดยใช้ mammoth.js, ไฟล์ Excel (.xlsx) โดยใช้ SheetJS และไฟล์เอกสาร PDF (.pdf) โดยใช้ pdf.js เพื่อให้ AI นำข้อความดิบไปใช้วิเคราะห์ต่อ

💬 แชทโต้ตอบโต้ตอบต่อเนื่อง (Multi-turn Chat)

แผงควบคุมหลักเป็นระบบแชทแบบโต้ตอบต่อเนื่องสะสมความจำ (Multi-turn) ผู้ใช้สามารถสนทนากล่อมคำ สั่งงานให้สรุป คัดย่อ ร่างเนื้อหาเฉพาะ หรือส่งงานตรวจทานเพิ่มเติมได้อย่างยืดหยุ่น โดยสามารถกดปุ่ม "เริ่มคุยใหม่" เพื่อล้างค่าประวัติประมวลผลได้ทันที

✔ ปุ่มแก้ไขข้อความรายจุด (Granular Control)

เพื่อป้องกันไม่ให้ข้อมูลทั้งแผ่นเอกสารถูกลบหรือเขียนทับโดยไม่ได้ตั้งใจ ผลวิเคราะห์คำแนะนำจะถูกแสดงเป็นการ์ดแยกจุดเด่นๆ พร้อมปุ่ม **`✔ แก้ไข`** เพื่อใช้ความสามารถ OfficeJS เขียนทับเฉพาะคำที่เลือกเป็นรายคำได้อย่างปลอดภัย

🔑 วิธีสร้างและติดตั้ง Gemini API Key

1

ไปยัง Google AI Studio

เปิดบราวเซอร์แล้วเข้าไปที่เว็บไซต์ Google AI Studio

2

สร้าง API Key ใหม่

ล็อกอินด้วยบัญชี Google จากนั้นคลิกปุ่ม "Get API Key" หรือ "Create API Key" ทางด้านซ้าย และเลือกสร้างคีย์ (คีย์ที่สร้างจะสามารถเลือกเป็นคีย์ฟรีสำหรับงานทดสอบได้)

3

นำมาใส่ใน Add-in

เมื่อคัดลอกคีย์มาแล้ว ให้คลิกปุ่มแฮมเบอร์เกอร์เมนู (☰) บริเวณมุมซ้ายบนของแถบ Add-in บนโปรแกรม Word แล้ววางรหัสคีย์ลงในกล่องข้อความ และเลือกโมเดลที่แนะนำ (เช่น gemini-3.1-flash-lite)

วิธีติดตั้ง Add-in ลงบน Microsoft Word (Installation Guide)

☁️ ช่องทางที่ 1: การใช้งานจริงผ่านคลาวด์ Vercel (สะดวกสุด)

แอปพลิเคชันเวอร์ชันอ้างอิงได้รับการ Deploy สำเร็จบนอินเทอร์เน็ตที่ลิงก์ https://office-web-add-in.vercel.app ทำให้ไม่จำเป็นต้องรัน Server ในเครื่องคอมพิวเตอร์ของคุณเอง

ขั้นตอนการติดตั้ง Catalog:

  1. สร้างโฟลเดอร์สำหรับเก็บ Manifest บนเครื่อง เช่น C:\AddinManifests\ จากนั้นวางไฟล์ manifest.xml ไว้ในนั้น
  2. เปิดโฟลเดอร์ คลิกขวา -> Properties -> แท็บ Sharing -> กด Share... เพื่อเปิดการแชร์ในเครื่องและคัดลอก Network Path (เช่น \\PCName\AddinManifests)
  3. เปิดโปรแกรม Word ไปที่เมนู ไฟล์ (File) -> ตัวเลือก (Options) -> ศูนย์ความเชื่อถือ (Trust Center) -> การตั้งค่าศูนย์ความเชื่อถือ (Trust Center Settings)
  4. เลือกแท็บ แค็ตตาล็อก Add-in ที่เชื่อถือได้ (Trusted Add-in Catalogs)
  5. กรอก Network Path ลงในช่อง URL แค็ตตาล็อก จากนั้นกด เพิ่มแค็ตตาล็อก (Add catalog) และติ๊กเลือก แสดงในเมนู (Show in Menu) จากนั้นคลิกตกลงแล้วทำการปิดเปิดโปรแกรม Word ใหม่หนึ่งครั้ง
  6. เปิดหน้ากระดาษ Word ไปที่แถบเมนู แทรก (Insert) -> คลิกปุ่ม Add-ins -> เลือก โฟลเดอร์ที่แชร์ (Shared Folder) จะพบปุ่มเรียกใช้งาน Gemini Assistant โผล่ขึ้นมาให้กดเปิดครับ

💻 ช่องทางที่ 2: การเปิดรัน Server ในเครื่องตัวเอง (Local Development)

สำหรับนักพัฒนาที่ต้องการแก้ไขปรับปรุงตรรกะในไฟล์โค้ด JS หรือ CSS เพิ่มเติม:

1. ติดตั้ง Dependencies และรันแอป

เปิด Terminal ในโฟลเดอร์โปรเจกต์และพิมพ์คำสั่งดังนี้:

# ติดตั้ง NodeJS แพ็กเกจที่เกี่ยวข้อง
npm install

# รัน Server จำลองโฮสต์โลคัล
npm run dev

2. เชื่อมต่อเข้า Word

เปิดโปรแกรม Word และเข้าผ่านแท็บแคตตาล็อกโฟลเดอร์แชร์ เช่นเดียวกับแบบคลาวด์ แต่ตรวจสอบไฟล์ Manifest ให้ชี้ปลายทางมายัง HTTPS Port ของเซิร์ฟเวอร์จำลองในเครื่องของคุณเอง (เช่น https://localhost:3000/taskpane.html)
