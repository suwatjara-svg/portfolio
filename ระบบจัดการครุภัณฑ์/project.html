คู่มือการติดตั้งระบบ

ขั้นตอนสำหรับนำโค้ดไปติดตั้งบน Google Apps Script และเตรียมระบบให้พร้อมใช้งาน

1) เตรียม Google Sheets และโฟลเดอร์รูป

  • สร้าง Google Sheets ใหม่สำหรับเป็นฐานข้อมูล
  • สร้างโฟลเดอร์ Google Drive สำหรับเก็บรูปครุภัณฑ์
  • คัดลอก Folder ID จาก URL ของโฟลเดอร์

2) สร้างโปรเจกต์ Apps Script

  • เปิด Google Sheets แล้วเลือก Extensions > Apps Script
  • วางโค้ด backend ลงในไฟล์ Code.gs
  • สร้างไฟล์ HTML ชื่อ Index แล้ววางโค้ดหน้าเว็บ

3) ตั้งค่าโฟลเดอร์รูปภาพ

แก้ค่า FOLDER_ID ใน Code.gs ให้เป็น Folder ID ที่เตรียมไว้ และตรวจสิทธิ์ของบัญชีผู้ติดตั้ง

4) สร้างตารางเริ่มต้น

เรียกใช้ฟังก์ชัน setupSheets() หนึ่งครั้ง เพื่อตั้งหัวตาราง Users, Settings, Assets และ AuditLogs

5) Deploy เป็น Web App

  • เลือก Deploy > New deployment > Web app
  • กำหนดผู้มีสิทธิ์เข้าถึงให้เหมาะกับหน่วยงาน
  • อนุญาตสิทธิ์ Google Sheets และ Google Drive ให้ครบ

ข้อควรทำก่อนใช้งานจริง

  • เปลี่ยนรหัสผ่านเริ่มต้นของผู้ดูแลระบบทันที
  • กำหนดสิทธิ์ผู้ใช้และสิทธิ์เข้าถึงโฟลเดอร์รูปให้เหมาะสม
  • สำรองข้อมูล Google Sheets และทดสอบเพิ่ม แก้ไข ค้นหา และลบรายการ
